# Bayesian backpropagation in PyTorch

Gaussian moment layers, explicit backward messages, and distinct EP/MFVI
objectives, using `torch.nn.Module` and local `torch.func.vjp`. The reader
places mathematics before code, numerical output and interpretation.

- [Executed notebook](README.ipynb)
- [HTML reader](README.html)
- [Separately typeset PDF](README.pdf)

- [Mathematical coverage of the R/TensorFlow reader](MATH_COVERAGE.md)
- [Colab validation](COLAB_VALIDATION.md)

Gaussian/EP/MFVI equivalence and same-belief approximation experiments execute
in the notebook. MNIST, CIFAR-10, SST-2 and CLINC chapters recompute uncertainty
tables and plots from original PyTorch prediction records. Historical training
time is not notebook rebuild time. No R-generated output, checkpoint or dataset
is bundled.

The reader expands the Gaussian bridge, local layer maps, EP/MFVI heads,
updates, covariance carriers, model definitions, and short experiment calls.
Longer execution and plotting routines are included but collapsed. The PDF
prints the key code and retains all results; complete support remains in the
notebook and linked source files. Exact source excerpts are labelled so they
are not mistaken for additional executed cells.

## Code reading order

| Module | Role |
|---|---|
| `geometry.py` | Gaussian coordinate conversion and finite updates |
| `layers.py`, `graph.py` | Affine/Conv2d/ReLU/pooling/branch maps and literal/projected reverse |
| `heads.py`, `inference.py` | Different EP and MFVI objectives and updates |
| `gaussian_chain.py`, `tutorial_evidence.py` | Exact references and MC fidelity checks |
| `correlation.py` | Shared activation factors and structured weight covariance |
| `optimizers.py`, `training.py`, `benchmark.py` | Finite optimizer choices and minibatch execution |
| `models.py`, `architectures.py` | MLP, LeNet, ResNet-20 and DenseNet-40 |
| `metrics.py`, `plotting.py`, `results.py` | Common uncertainty definitions and result regeneration |
| `inspect.py`, `transformer_inspection.py` | torchinfo summaries and checked ONNX export |
| `../tensorflow/python/gpt2`, `../tensorflow/python/blob_mirror` | Original transformer training/prediction code |

BLoB-style conditional Gaussian adapters are an MFVI variant with a different
LoRA factorization and split likelihood/KL update; they are not EP. The compact
image trainer and the historical optimized image runs are also distinguished.

## Rebuild

Run from the repository root. HTML and PDF rendering also require Pandoc and
XeLaTeX, respectively.

```bash
python -m pip install -e './pytorch[tutorial,inspect]' pytest
PYTHONPATH=pytorch/src python -m pytest pytorch/tests -q
jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=1800 pytorch/README.ipynb
python site/build.py
python pytorch/build_full_pdf.py
```

The standalone notebook embeds its Python support and evidence and can be
copied to a Python Colab runtime. Its default rebuilds numerical checks and
figures; it does not start historical training. Public-model training programs and the scope of each result are described in
the final chapter.

`torchinfo` supplies layer summaries. [Netron](https://github.com/lutzroeder/netron)
views checked ONNX files generated by `python pytorch/export_architectures.py`.
These describe the executable mean network, not backward messages. Transformer
summaries execute random-weight shape checks, not pretrained evaluations.

The learned-ResNet study now compares all three implementations on the same
beliefs, inputs and objectives. A separate high-precision Monte Carlo reference
measures approximation error. Native Dirty-MNIST training validates the full
compact workflow; its measured times are kept separate from historical optimized
runs. GPT-2 and RoBERTa have checked ONNX architecture views. The fixed-belief
Gaussian GPT-2 replay compares predictions and all adapter likelihood derivatives
against native JAX; it does not claim a new training run.
